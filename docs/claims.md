# Claims

## Supported By Final Full-Scale Evidence

1. In a stylized manipulation world with visually censored hidden contact classes and hidden decorative variables, dense hidden-state entropy can spend touch budget on variables that do not affect the pending manipulation contact.
2. Contact-equivalence probing succeeds when its probe library contains actions that split the posterior over contact-outcome classes.
3. At budget four in the final main suite, dense entropy reaches 0.083 success, critical-cell entropy reaches 0.425, expected-regret probing reaches 0.825, sampled equivalence reaches 0.967, exact contact-equivalence reaches 1.000, and dense contact-only reaches 1.000.
4. Decorative-variable scaling supports the mechanism: with 256 decorative bits at budget four, dense entropy reaches 0.079 while contact-equivalence remains 1.000.
5. Boundary controls narrow the claim: with zero decorative bits or an oracle contact-only probe library, dense entropy also reaches 1.000.
6. Noise stress is a real limitation: contact-equivalence at budget four falls to 0.442 under 20% symmetric binary noise.
7. Probe-library ablations show that the representation alone is insufficient; contact-equivalence falls to 0.433 in the cells-only/no-sweeps control.

## Formal Claims To Check

1. If task loss depends on hidden geometry only through a contact-outcome map, then two geometries with the same map are decision-equivalent for that task.
2. A probe that splits contact-outcome classes can reduce task regret even when it does not maximally reduce dense hidden-state entropy.
3. Dense information gain can be distracted whenever irrelevant hidden variables offer larger entropy reduction than the available contact probes.

## Unsupported Or Only Partially Supported

1. Real tactile sensors will provide clean enough contact signatures without calibration drift.
2. Exact contact-equivalence maintenance scales directly to high-dimensional 3D geometry.
3. The mechanism outperforms learned visuo-tactile policies or reconstruction-driven planners on real robots.
4. The mechanism handles deformable, articulated, or actively changing objects without a transition-level quotient.
5. Contact-equivalence outperforms a system that already has an oracle contact-relevance filter.
