- If a prior paper already performs tactile shape reconstruction, the new paper cannot claim touch-for-shape as novel.
- If a prior paper already uses active touch, the new paper cannot claim active exploration as novel.
- If a prior paper already fuses vision and touch, the new paper cannot claim multimodal fusion as novel.
- The remaining defensible gap is narrower: represent the set of geometries that vision cannot distinguish, then use contacts to split that set only where the difference changes future manipulation feasibility.
