- Ignored failures: does not isolate whether the tactile signal distinguishes visually identical but contact-different objects | can be overconfident when the visible pose is correct but the occluded contact boundary is wrong
- Makes less novel: using tactile contacts to reconstruct object shape
- Leaves open: a mechanism that represents vision-censored geometry as an equivalence class and uses contact to split only manipulation-relevant alternatives
